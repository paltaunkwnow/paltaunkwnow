<br/>

Desarrollador apasionado por la creación de aplicaciones web modernas, robustas e interactivas. Cuento con sólida experiencia en tecnologías de última generación para desarrollo web como **Next.js**, **TypeScript**, **React**, **Node.js** y **Express.js**, construyendo interfaces rápidas y backend escalables.

En el ámbito de la **Ciberseguridad**, me desempeño e instruyo activamente como **Investigador OSINT** (Open Source Intelligence), explorando el rastreo de huella digital, inteligencia de fuentes abiertas, pruebas de penetración (**Penetration Testing**), análisis de vulnerabilidades (**OWASP**) y seguridad de redes informáticas.
